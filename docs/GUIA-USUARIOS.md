# Entrar en «Gestión del retiro» desde tu ordenador, tablet o móvil

No tienes que instalar nada. Solo necesitas un navegador (Chrome, Edge, Safari, Firefox…) y dos datos que te da quien preparó el servidor:

- la **dirección**, por ejemplo `http://192.168.1.20:3000`;
- el **código de acceso**, una clave larga de letras y números.

> Tienes que estar conectado a la **misma red (Wi‑Fi)** que el servidor, y el servidor tiene que estar encendido con la aplicación abierta.

## Desde un ordenador (Windows o Mac)

1. Abre el navegador.
2. Escribe la dirección **en la barra de direcciones** (arriba del todo, no en el buscador de Google) y pulsa Intro. Escríbela tal cual, con `http://` y los números del final (`:3000`).
3. Pega o escribe el **código de acceso** y pulsa **Entrar**.
4. Para no tener que escribirla otra vez, guárdala:
   - **Favorito:** pulsa la estrella ☆ de la barra de direcciones.
   - **Acceso directo en el escritorio (Chrome o Edge):** menú ⋮ → **Guardar y compartir** (o **Más herramientas**) → **Crear acceso directo…** → marca **Abrir como ventana** → **Crear**. Queda un icono en el escritorio que se abre como una aplicación.

El código se recuerda **30 días** en ese navegador. Pasado ese tiempo, te lo volverá a pedir.

## Desde una tablet o un móvil

### Android (Chrome)

1. Conéctate a la Wi‑Fi del servidor.
2. Abre **Chrome** y escribe la dirección en la barra de arriba.
3. Escribe el código de acceso y pulsa **Entrar**.
4. Para tener un icono en la pantalla de inicio: menú **⋮** → **Añadir a pantalla de inicio** → **Añadir**.

### iPhone y iPad (Safari)

1. Conéctate a la Wi‑Fi del servidor.
2. Abre **Safari** y escribe la dirección en la barra de direcciones.
3. Escribe el código de acceso y pulsa **Entrar**.
4. Para tener un icono en la pantalla de inicio: botón **Compartir** (cuadrado con una flecha) → **Añadir a pantalla de inicio** → **Añadir**.

En pantallas pequeñas algunas tablas son anchas: desliza hacia los lados para ver todas las columnas. Para **imprimir** cartas, mejor desde un ordenador con impresora.

## Si no carga

| Lo que ves | Qué hacer |
|---|---|
| «No se puede acceder a este sitio» o la página se queda cargando | Comprueba que estás en la **misma Wi‑Fi** que el servidor (no en la red de invitados ni con datos móviles) y que el servidor está encendido con la aplicación abierta. |
| Funcionaba y ya no | La dirección pudo cambiar. Pide la dirección actual a quien gestiona el servidor (sale en el título de su ventana) y actualiza tu favorito o icono. |
| Te pide el código otra vez | Han pasado 30 días, o se borraron los datos del navegador. Vuelve a escribirlo. |
| «Código incorrecto» | Cópialo de nuevo, sin espacios al principio ni al final. |
| El navegador avisa de que la conexión «no es segura» | Es normal: la conexión va solo por la red local (`http://`). No escribas el código en redes Wi‑Fi públicas. |

## Cuidado con los datos

Las cartas son personales. No compartas el código de acceso fuera del equipo del retiro, y si usas un ordenador o una tablet de otra persona, borra después los datos de navegación del sitio.
